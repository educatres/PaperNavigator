單元測試涵蓋：90%→92% 的 percentage points／relative %、零基準、資料集不同比較阻擋、硬體差異降級、Pass 1 五個 C、Pass 2 精簡回應相容、Pass 3 與表格部分回應相容、所有分析階段缺少區段、單一 JSON object、Markdown／前後文字／尾逗號容錯、截斷辨識、三次格式重做上限、依錯誤類型修正提示、網路／權限錯誤不誤重試、重做 token 累計、固定 Schema 契約、Evidence 頁碼範圍、摘錄正規化核對、CSV 公式注入、完整 Provider 設定保存／清除，以及舊專案 highlight 遷移。

## 人工驗收文件組

- A：正常文字 PDF，含 Methods、baseline、多個 Table 與 ablation。
- B：同任務但不同 dataset split 或 pretraining。
- C：低品質掃描／雙欄與圖表較多 PDF。
- D：密碼保護或損毀 PDF。

## 人工驗收步驟

1. 匯入 A，確認 magic bytes、頁數、預覽與文字品質提示。
2. 輸入測試 Key，按「讀取模型清單」確認只出現 API 實際回傳的 Gemma／OSS 120B；執行「測試連線」確認明確顯示「測試成功」及模型回覆，再驗證儲存、重整保留與紅色清除功能。
3. 執行 Pass 1；確認全畫面半透明遮罩顯示目前步驟、等待時間與取消按鈕，再檢查五個 C 都有 evidence 或「未找到」，點 evidence 跳 PDF。
4. 執行 Pass 2；確認 prior work 與 paper proposed 分開，缺值不是 0，且精簡回應的缺少欄位會補明確預設而非整份作廢。
5. 指定一個表格；確認只稱本文所報告的比較結果，消融最大下降不被稱為因果證明；AI 省略任一欄位時仍保留其餘可用結果，不顯示「等 N 個欄位」。
6. 執行 Pass 3；確認 missing／implicit 可見，研究題目標示為 AI 建議。
7. 加入 B；不同 split 不得出現全體第一名。同條件資料顯示 absolute、relative 與 percentage points。
8. 以 C 驗證低文字品質警示與人工核對狀態；以 D 驗證拒絕原因。
9. 匯出 Markdown、CSV、JSON、BibTeX、RIS；搜尋輸出確認不含 Key 或 PDF bytes。
10. 在 PDF 連續捲動頁面，確認縮小、放大、螢幕同寬與 100% 控制；在文字層選取文字後套用四種螢光色，同次多行選取只產生一筆記錄且只保存第一個區塊，重整後確認 PDF 原檔及標記都自動恢復；於「重點標記」改色、刪除並產生 Markdown AI 摘要／翻譯，確認結果不重複原文、顯示在原文下方且可匯出；切換刪除模式確認游標為叉號。
11. 以測試模型故意回傳 Markdown code fence 或前後文字，確認本機直接修復且不重做；再測試 schema 不符內容，確認先把原始輸出交給一次格式化 LLM，格式化成功後保留結果與累計 usage；若格式化仍失敗，再確認遮罩依序顯示第 1/3、2/3、3/3 次重做，三次重做皆失敗時保留原有分析。
12. 完成第二遍後，按「總覽」左側的筆記按鈕；確認純文字筆記視窗可自由拖曳、縮放與關閉，重新開啟後內容仍存在；其右側的星號「重點標記」與一般分頁之間有垂直分隔線。加入螢光重點後確認第三遍 prompt 會帶入筆記與標記；更新內容後可再次執行第三遍，完成後按分頁列的「完整報告」，確認 A4 報告直接在瀏覽器新分頁開啟且沒有下載檔案。
13. 不啟用工具時，在 PDF 文字層拖曳並複製文字，確認不會建立註釋。再切換「圈選翻譯」，以灰色空心矩形連續圈住至少三個跨行段落；確認操作過程沒有逐字高亮，每個區域只建立一個位於左上方的灰色虛線「文」標記，且待翻譯原文只包含框內文字。按「翻譯已選段落」，確認三段依序在背景翻譯且仍能操作閱讀器；中途停止後，已完成段落保留、未完成標記仍可再次批次接續。移入或點擊「文」後，確認譯文框持續顯示、可用標題列任意拖曳，且只有按右上角 X 才關閉；滑鼠離開「文」時來源區域的灰色空心框必須立即消失，即使譯文框仍開啟。確認待翻譯與已翻譯段落皆可逐筆或全部清除，且介面不再提供全文／自動逐段翻譯。
13a. 切換「圈選摘要」，在與翻譯相同及不同的位置建立至少三個區域；確認每個區域出現「摘」標記，與同位置的「文」錯開而不重疊。按「摘要已選段落」，確認 AI 只摘要框內文字、依序在背景處理，且停止／接續、常駐可拖曳摘要框、X 關閉、逐筆清除及全部清除均與圈選翻譯一致。
13b. 在已完成的「文」與「摘」浮動框分別按「編輯」：修改後按「取消」確認原值不變；再次修改並按「儲存」或 Ctrl/Cmd＋Enter，確認新值立即顯示，重新整理後仍保留。確認空白內容無法儲存，且待處理項目不會把來源文字誤當成可編輯結果。
14. 在 PDF Viewer 按「圈選截圖」，於單一頁面由任一方向拖曳矩形；確認放開後「截圖」分頁增加圖片，圖片只含 PDF 原文畫面，可定位原頁並刪除。重新整理後截圖仍存在。
15. 按 PDF Viewer 的「收合」，確認閱讀內容擴張且右側保留 PDF 恢復按鈕；重新整理後維持收合狀態。完成三遍後開啟「完整報告」，確認文件最後的「個人閱讀附錄」依序包含重點標記（含 AI 摘要／翻譯）、截圖與筆記。
13. 使用超過原文字數上限且第二頁有獨特內容的測試 PDF，確認第一遍與第二遍的請求內容仍包含最後頁面的頁碼標記與文字。

真實 API 的 CORS、模型權限與額度取決於使用者帳號，必須使用該帳號的測試 Key 完成最終連線驗收；repository 與自動測試不保存真實 Key。
